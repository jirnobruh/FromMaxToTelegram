# MAX to Telegram Bot (`max-to-tg-bot`)

Сервис для автоматической и надёжной пересылки сообщений из корпоративного мессенджера MAX в Telegram (каналы, супергруппы, топики форумов).

## Особенности
- Построен на базе `aiogram 3.x` и асинхронной библиотеки `max-client`.
- Поддержка топиков в форумах Telegram (`message_thread_id`).
- Пересылка текста, форвардов, медиагрупп (фото, видео, документы), голосовых сообщений.
- Гибкий маппинг чатов MAX -> чаты/топики Telegram.
- Автоматический реконнект и healthcheck.

## Настройка и запуск

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполните токены и идентификаторы чатов в `.env`.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите сервис:
   ```bash
   python -m src.main
   ```
